# User Story

**Как сотрудник компании**  
**Я хочу забронировать подходящую свободную переговорную комнату на нужную дату и время с необходимым оборудованием**  
**Чтобы провести встречу в подходящих условиях**

## Критерии приёмки

```gherkin
Feature: Бронирование переговорной комнаты

Scenario: Успешное бронирование переговорной комнаты
Given пользователь авторизован в личном кабинете
And пользователь открыл сервис "Аренда комнат"
When пользователь указывает допустимую дату, количество участников и необходимое оборудование
And нажимает кнопку "Поиск"
Then система отображает подходящие переговорные комнаты
And для каждой комнаты отображает свободные часовые интервалы
When пользователь выбирает комнату и свободный временной интервал
And нажимает кнопку "Забронировать"
Then система отображает окно подтверждения с параметрами бронирования
When пользователь нажимает "Да"
Then система повторно проверяет доступность выбранной комнаты на указанные дату и время
When выбранный временной интервал свободен
Then система создаёт бронирование
And отображает информацию о созданной брони

Scenario: Пользователь не подтверждает бронирование
Given пользователь авторизован в личном кабинете
And пользователь открыл сервис "Аренда комнат"
When пользователь указывает допустимую дату, количество участников и необходимое оборудование
And нажимает кнопку "Поиск"
Then система отображает подходящие переговорные комнаты
And для каждой комнаты отображает свободные часовые интервалы
When пользователь выбирает комнату и свободный временной интервал
And нажимает кнопку "Забронировать"
Then система отображает окно подтверждения с параметрами бронирования
When пользователь нажимает "Нет"
Then система не создаёт бронирование

Scenario: Выбранную комнату успел забронировать другой пользователь
Given пользователь авторизован в личном кабинете
And пользователь открыл сервис "Аренда комнат"
When пользователь указывает допустимую дату, количество участников и необходимое оборудование
And нажимает кнопку "Поиск"
Then система отображает подходящие переговорные комнаты
And для каждой комнаты отображает свободные часовые интервалы
When пользователь выбирает комнату и свободный временной интервал
And нажимает кнопку "Забронировать"
Then система отображает окно подтверждения с параметрами бронирования
When пользователь нажимает "Да"
Then система повторно проверяет доступность выбранной комнаты на указанные дату и время
When выбранный временной интервал уже занят
Then система не создаёт бронирование
And отображает сообщение "Бронирование недоступно. Комнату успел забронировать кто-то другой"

Scenario: На выбранную дату нет подходящих комнат
Given пользователь авторизован в личном кабинете
And пользователь открыл сервис "Аренда комнат"
When пользователь указывает допустимую дату, количество участников и необходимое оборудование
And нажимает кнопку "Поиск"
Then система сообщает об отсутствии свободных комнат
And предлагает выполнить поиск ближайших доступных вариантов

Scenario: Найдены ближайшие подходящие комнаты
Given пользователь авторизован в личном кабинете
And пользователь открыл сервис "Аренда комнат"
When пользователь указывает допустимую дату, количество участников и необходимое оборудование
And нажимает кнопку "Поиск"
Then система выводит сообщение "На выбранную дату нет свободных комнат"
And система предлагает выполнить поиск ближайших доступных вариантов
When пользователь нажимает кнопку "Поиск вариантов"
Then система выполняет поиск на один день до и один день после выбранной даты
When подходящие варианты найдены
Then система отображает дату, комнаты и их свободные часовые интервалы

Scenario: Поиск ближайших вариантов при выборе текущей даты
Given пользователь авторизован в личном кабинете
And пользователь открыл сервис "Аренда комнат"
When пользователь указывает текущую дату, количество участников и необходимое оборудование
And нажимает кнопку "Поиск"
Then система выводит сообщение "На выбранную дату нет свободных комнат"
And система предлагает выполнить поиск ближайших доступных вариантов
When пользователь нажимает кнопку "Поиск вариантов"
Then система выполняет поиск на один день после выбранной даты

Scenario: Ближайшие подходящие комнаты не найдены
Given пользователь авторизован в личном кабинете
And пользователь открыл сервис "Аренда комнат"
When пользователь указывает допустимую дату, количество участников и необходимое оборудование
And нажимает кнопку "Поиск"
Then система выводит сообщение "На выбранную дату нет свободных комнат"
And система предлагает выполнить поиск ближайших доступных вариантов
When пользователь нажимает кнопку "Поиск вариантов"
Then система выполняет поиск на один день до и один день после выбранной даты
When подходящие варианты не найдены
Then система выводит сообщение "Нет подходящих свободных комнат. Измените параметры поиска и попробуйте ещё раз"

Scenario: Выбор нескольких последовательных слотов
Given пользователь авторизован в личном кабинете
And пользователь открыл сервис "Аренда комнат"
When пользователь указывает допустимую дату, количество участников и необходимое оборудование
And нажимает кнопку "Поиск"
Then система отображает подходящие переговорные комнаты
And для каждой комнаты отображает свободные часовые интервалы
When пользователь выбирает в одной из комнат последовательные интервалы "10:00-11:00" и "11:00-12:00"
And подтверждает бронирование
Then система создаёт одно бронирование
And устанавливает время начала "10:00"
And устанавливает время окончания "12:00"
```

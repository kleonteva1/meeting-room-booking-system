# Use Case

## Бронирование переговорной комнаты

| Параметр | Описание |
| --- | --- |
| Имя сценария | Бронирование переговорной комнаты |
| Цель | Забронировать подходящую переговорную комнату на выбранную дату и время |
| Краткое описание | Процесс поиска свободной переговорной комнаты по заданным параметрам и создания бронирования |
| Действующие лица | Сотрудник, Система бронирования |
| Активатор | Сотрудник открывает сервис «Аренда комнат» |

## Предварительные условия

- Сотрудник авторизован в личном кабинете.
- Информация о переговорных комнатах есть в системе.
- Актуальная информация о существующих бронированиях есть в системе.

## Основной поток

1. Сотрудник открывает сервис «Аренда комнат».
2. Система отображает схему переговорных комнат и форму поиска.
3. Сотрудник при необходимости просматривает информацию о комнате на схеме.
4. Сотрудник указывает дату, количество участников и необходимое оборудование.
5. Сотрудник нажимает кнопку «Поиск».
6. Система определяет переговорные комнаты, соответствующие количеству участников и требованиям к оборудованию.
7. Система определяет свободные часовые интервалы подходящих комнат на выбранную дату.
8. Система отображает найденные комнаты, их вместимость, оборудование и доступные временные интервалы.
9. Сотрудник выбирает одну комнату и один или несколько последовательных свободных интервалов.
10. Система объединяет несколько последовательных интервалов в единый интервал бронирования.
11. Сотрудник нажимает кнопку «Забронировать».
12. Система отображает параметры создаваемого бронирования и запрашивает подтверждение.
13. Сотрудник выбирает «Да», подтверждая бронирование.
14. Система повторно проверяет доступность выбранной комнаты на выбранный временной интервал.
15. Система устанавливает, что выбранный интервал остаётся свободным.
16. Система создаёт бронирование со статусом `ACTIVE`.
17. Система отображает сотруднику информацию об успешно созданном бронировании.

## Альтернативный поток

### На выбранную дату нет подходящих свободных комнат

1. На шаге 7 система определяет, что свободных вариантов нет.
2. Система сообщает об отсутствии доступных комнат и предлагает выполнить поиск ближайших вариантов.
3. Сотрудник выбирает «Показать варианты».
4. Система выполняет поиск на один день до и один день после выбранной даты с сохранением количества участников и требований к оборудованию.
5. Если исходная дата является текущей, система выполняет поиск только на следующий календарный день.
6. Система отображает найденные даты, комнаты и свободные интервалы.
7. Сценарий продолжается с шага 9 основного потока.

### Ближайшие варианты отсутствуют

1. Система не находит подходящих комнат при поиске ближайших вариантов.
2. Система сообщает, что подходящих свободных комнат нет.
3. Система предлагает изменить параметры поиска.
4. Система не создаёт бронирование.

### Сотрудник не подтверждает бронирование

1. На шаге 13 сотрудник выбирает «Нет».
2. Система не создаёт бронирование.

## Исключения

### Выбранную комнату успел забронировать другой пользователь

1. На шаге 15 система обнаруживает, что выбранный интервал уже занят.
2. Система не создаёт бронирование.
3. Система сообщает: «Бронирование недоступно. Комнату успел забронировать кто-то другой».

### Техническая ошибка

1. При создании бронирования возникает техническая ошибка.
2. Система не создаёт бронирование.
3. Система сообщает пользователю об ошибке.

## Результат

Создано одно бронирование выбранной переговорной на указанную дату с непрерывным временным интервалом и статусом `ACTIVE`.

## Дополнение

- Бронирование возможно только в период 10:00–18:00.
- Минимальный интервал бронирования —1 час.

# Система бронирования переговорных комнат
Учебный проект по системному анализу — проектирование системы онлайн-бронирования переговорных комнат для сотрудников компании.
## О проекте
Система позволяет сотрудникам находить свободные переговорные комнаты по заданным параметрам, просматривать доступные временные интервалы, создавать, изменять и отменять бронирования.
В рамках проекта выполнены сбор и формализация требований, описание пользовательских сценариев, моделирование процессов и взаимодействий, проектирование структуры данных, создание прототипа интерфейса и SQL-запросов.
